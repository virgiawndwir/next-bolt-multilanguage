# WebSite - Modern Web Solutions

A modern, responsive website built with Next.js 15, TypeScript, and Tailwind CSS featuring multilingual support and beautiful animations.

## 🚀 Features

- **Modern Design** - Clean, professional UI with smooth animations
- **Multilingual Support** - Switch between Indonesian and English with one click
- **Responsive Layout** - Optimized for all devices (mobile, tablet, desktop)
- **Hero Slider** - Dynamic content slider with auto-play functionality
- **Interactive Components** - Hover effects, transitions, and micro-interactions
- **Performance Optimized** - Built with Next.js 15 for optimal performance
- **Type Safe** - Full TypeScript implementation

## 🛠️ Tech Stack

- **Framework:** Next.js 15
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **State Management:** React Context API
- **Build Tool:** Webpack (via Next.js)

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/website.git
cd website
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🌍 Language Support

The website supports two languages:
- **Indonesian (ID)** - Default language
- **English (EN)** - Toggle via language button in navbar

All static text content is translated including:
- Navigation menu
- Hero slider content
- Features section
- Statistics labels
- Call-to-action sections
- Footer content

## 📱 Responsive Design

The website is fully responsive with breakpoints for:
- **Mobile:** < 768px
- **Tablet:** 768px - 1024px
- **Desktop:** > 1024px
